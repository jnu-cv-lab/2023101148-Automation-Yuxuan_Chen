# 实验 8：PyTorch 入门与图像分类

## 一、实验目标

本实验要求使用 PyTorch 完成一个简单的图像分类任务，完整体验深度学习图像分类的基本流程：

**数据加载 → 模型定义 → 训练 → 验证 → 测试 → 结果分析**

完成实验后，学生应能够理解深度学习图像分类任务的基本组成，并能够独立运行一个简单的 CNN 图像分类实验。

## 二、实验任务

### 任务 1：环境准备

- 安装并测试 PyTorch、torchvision、NumPy、Matplotlib 等 Python 库
- 能够成功导入 PyTorch
- 能够判断当前环境是否支持 GPU
- 能够正常运行一个简单的 PyTorch 张量操作

### 任务 2：加载图像数据集

- 使用 MNIST 或 CIFAR-10 数据集完成图像分类实验
- 加载训练集和测试集
- 将训练集进一步划分为训练集和验证集
- 显示至少 8 张样本图像，标注每张图像对应的真实类别
- **基础要求**：MNIST  
  **进阶要求**：CIFAR-10

### 任务 3：定义 CNN 模型

- 设计一个简单的卷积神经网络模型
- 模型至少应包含：卷积层、激活函数、池化层、全连接层和输出层
- 模型输入应匹配所选数据集的图像尺寸
- 模型输出类别数应与数据集类别数一致
- 在实验报告中写出模型结构

### 任务 4：训练模型

- 使用训练集训练 CNN 模型
- 选择合适的损失函数
- 选择一种优化器
- 至少训练 5 个 epoch
- 每个 epoch 记录：
  - training loss
  - training accuracy

### 任务 5：验证模型

- 使用验证集评估模型训练效果
- 每个 epoch 后在验证集上测试模型
- 记录：
  - validation loss
  - validation accuracy
- 比较训练集和验证集上的表现差异

### 任务 6：测试模型

- 训练完成后，使用测试集评估最终模型性能
- 输出：
  - 测试集 loss
  - 测试集 accuracy
- 显示至少 8 张测试图像
- 显示每张图像的：
  - 真实类别
  - 模型预测类别

### 任务 7：绘制训练曲线

- 绘制 training loss 和 validation loss 曲线
- 绘制 training accuracy 和 validation accuracy 曲线
- 图形要求：
  - 横轴为 epoch
  - 纵轴为 loss 或 accuracy
  - 包含标题、坐标轴标签和图例

### 任务 8：结果分析

在实验报告中回答以下问题：

- 训练 loss 是否随着 epoch 增加而下降？
- 验证 accuracy 是否随着训练逐渐提升？
- 训练 accuracy 和验证 accuracy 是否存在明显差距？
- 如果存在明显差距，可能是什么原因？
- 哪些数字或类别更容易被错误分类？
- MNIST 和 CIFAR-10 哪个更难？为什么？
