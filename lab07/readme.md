# 作业8：传统机器学习方法用于图像分类
## 一、作业题目
传统机器学习方法在手写数字图像分类中的应用
## 二、作业目标
通过本次作业，要求同学们理解：图像如何转换为机器学习模型可以处理的特征向量；训练集和测试集的基本概念；常见传统机器学习分类方法的基本使用；不同分类器在同一图像分类任务中的表现差异；如何用准确率、混淆矩阵和错误样本分析评价分类结果。
## 三、数据集要求
本次作业建议使用 sklearn 自带的 digits 手写数字数据集。
数据集基本信息：
项目	内容
数据类型	手写数字灰度图像
图像大小	8 × 8
类别数量	10 类
类别标签	0 到 9
任务类型	图像分类
每张图像可以展开成一个 64 维特征向量，用于训练机器学习分类器。
## 四、作业任务
请完成以下任务。
- 任务 1：数据准备
加载手写数字图像数据集，并完成以下内容：
查看数据集中图像的数量；
查看每张图像的大小；
查看类别标签；
显示若干张样本图像及其真实标签。
- 任务 2：数据划分
将数据集划分为：训练集；测试集。要求测试集比例为 25% 左右。
说明训练集和测试集分别用于什么目的。
- 任务 3：特征表示
将每张图像转换为机器学习模型可以处理的特征向量。
要求说明：
一张 8 × 8 图像如何变成 64 维向量；
为什么传统机器学习方法通常需要这种特征转换；
原始像素作为特征有什么优点和局限。
- 任务 4：模型训练
请至少使用以下传统机器学习方法中的 五种 完成分类实验：
最近邻方法，KNN；
朴素贝叶斯分类器；
逻辑回归；
支持向量机，SVM；
决策树；
随机森林。
每种方法都需要完成：
训练模型；
在测试集上进行预测；
记录分类准确率。
- 任务 5：结果比较
将不同模型的测试准确率整理成表格。
表格格式参考如下：
模型	测试准确率
KNN	
Naive Bayes	
Logistic Regression	
SVM	
Decision Tree	
Random Forest	
要求根据实验结果回答：
哪个模型准确率最高？
哪个模型准确率最低？
不同模型之间的表现差异是否明显？
你认为产生差异的原因是什么？
- 任务 6：错误样本分析
选择一个表现较好的模型，分析其分类错误情况。
要求：
绘制或展示混淆矩阵；
找出若干个被错误分类的样本；
分析哪些数字最容易被混淆；
说明这些错误样本为什么可能被模型误判。
