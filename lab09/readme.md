# 第10次实验内容

本实验要求学生在上次 CNN 图像分类实验基础上，进一步分析 CNN 的训练过程、优化器影响、内部特征表示和错误分类样本。  
完成实验后，学生应能够：

- 理解优化器和学习率对模型训练的影响；
- 能够比较 SGD、Momentum 和 Adam 的训练效果；
- 能够可视化 CNN 的卷积核和 feature maps；
- 能够分析模型的错误分类样本；
- 能够使用曲线和混淆矩阵评价模型表现。

## 实验任务

### 任务 1：复用上次 CNN 模型
使用上次实验中的 MNIST 或 CIFAR-10 CNN 模型。  
不改变模型结构，重新训练模型，并记录训练过程。

### 任务 2：优化器对比
使用相同模型和相同数据集，分别使用以下优化器训练：
- SGD  
- SGD+Momentum  
- Adam  

记录每种优化器的：
- training loss  
- validation loss  
- training accuracy  
- validation accuracy  
- test accuracy  

### 任务 3：学习率对比
固定优化器为 Adam，分别尝试：
- 0.1  
- 0.01  
- 0.001  

比较不同学习率下 loss 曲线和 accuracy 曲线的变化。

### 任务 4：卷积核可视化
显示第一层卷积核。  
要求：
- 至少显示 8 个卷积核；
- 说明训练后的卷积核是否呈现某种边缘、方向或纹理特征；
- 简要说明卷积核是如何通过训练得到的。

### 任务 5：Feature map 可视化
选择一张测试图片，将其输入训练好的 CNN。  
显示第一层卷积输出的 feature maps。  
要求：
- 至少显示 8 张 feature maps；
- 观察不同 feature maps 对图像哪些区域有强响应；
- 简要说明不同卷积核提取了不同图像特征。

### 任务 6：错误分类样本分析
从测试集中找出模型预测错误的样本。  
显示至少 8 张错误分类图片。  
每张图片标注真实类别/预测类别。  
分析：
- 哪些类别最容易被混淆？
- 错误原因可能是什么？
- 如果要提高准确率，可以从数据、模型结构或训练方法上做哪些改进？

### 任务 7：混淆矩阵
绘制测试集混淆矩阵。  
分析：
- 对角线元素代表什么？
- 非对角线元素代表什么？
- 哪两个类别之间混淆最严重？
